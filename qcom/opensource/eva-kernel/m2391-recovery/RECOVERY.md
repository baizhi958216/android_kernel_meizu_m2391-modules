# M2391 EVA recovery

The Qualcomm GPL foundation is retained, including its later bounded persistent-buffer unmap implementation and buffer checks. Original platform static objects match (57 objects); sm8550 non-fatal-fault policy restored to zero. The original diagnostic-only user-persistent release hook is restored before the bounded implementation; it is not used as a substitute for buffer release.

The complete real Kbuild `msm/msm-eva.o` target passed with prepared Kalama/Crow core headers, LLVM LTO and CFI. Actual `.o.symversions` linked by the standard linker script reproduce all eight original exported CRCs, classes and namespaces. Public forwarders stay in their original compilation units so kernel type completeness remains natural. FastRPC's three private exports are guarded by a complete source-provider/source-EVA group; no original CRC is injected into source output.

Public opaque handles are independently referenced registry objects, not exposed instance pointers. Removal withdraws publication, wakes/drains in-flight operations, stops DSP/RPMSG/FastRPC producers, removes instance debugfs, closes real instances while HFI/IOMMU remain available, and then tears down HFI/IRQ/work/resources. Old descriptors retain inert handles; close remains idempotent and does not wait for arbitrary userspace close during unbind. Poll uses a handle-owned waitqueue bridged to the original instance event queue, preserving ordinary event wakeups. Private protocol requests return wire data/IOVAs, not internal fh/queue pointers.

HFI queue admission is stopped under its async spinlock before IRQ/work draining. IRQ registration uses NO_AUTOEN so a probe interrupt cannot enter uninitialized workqueue state. Three original fence workers are individually pinned before wake, joined before instance teardown, and observe stop between bounded synx waits. Debugfs proxies drain before their backing state is released.

FastRPC driver-core exit callbacks queue independent cleanup work rather than recursively unregistering a driver. Callback work pins the original device and compares device identity before acting, preventing delayed old callbacks from removing a replacement registration with the same handle. An ownership mutex serializes registration and cleanup; node removal first unpublishes, then waits for existing kernel references. DSP sessions are unlinked before real close. Both node-held and work-held device references are released on success, registration failure/timeout, rejection and stale-work skip. Stop closes queue admission before flushing work and destroying DSP locks.

Parent independently reviewed the handle/probe/remove, HFI/fence and final FastRPC cleanup locking. This validates source/build/lifecycle reasoning, not hardware execution.
