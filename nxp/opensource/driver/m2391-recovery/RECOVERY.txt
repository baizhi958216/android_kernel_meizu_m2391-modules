Remaining source safety changes are described below. Original OF/I2C tables,

Recovered module IPC context nq-nfc,10pages, line-number diagnostics with

Context is created before driver registration and destroyed after driver exit;
registration failure also drops the new context. No diagnostic stub is used.

Lifetime fixes: embedded structdevice/cdev_device_add pins private memory for
pending opens and retained descriptors; all hardware initialization precedes
cdev publication. Operation read leases allow normal blocking read, flush and
eSE ioctl response reads concurrently. Removal/failed publication first marks
removing and wakes read/coldreset queues before waiting for exclusive drain;
then drains IRQ, unpublishes cdev, releases owned GPIO/power/buffers and drops
owner. Old descriptors retain state and refuse hardware access. post_init
success and GPIO leases belong to the device rather than old module state;
clock lookup is reused and dropped, and failed regulator vote cannot double-put.

Cold-reset cancellation: reader never dereferences an ioctl-owned command buffer.
A spinlock protects transaction generation, expected OID and response capacity;
response reads snapshot those and NFC mode before allocation. Every header must
complete all3bytes and payload length must be positive, fit the snapshot and
transfer fully. Only the captured generation may publish status/clear pending;
signal/removal retirement cannot ACK a later request. Completion status is read
under the same lock. Header detection also requires ret>=3. Wire commands and
successful response/status semantics are retained; cancellation/short-frame
failures are handled explicitly. Secure/eSE-off ioctls stay concurrent, with
separate post_init/clock mutexes rather than a global ioctl lock.
